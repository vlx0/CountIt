# CountIt

Сколько в тексте **символов, слов** и **времени на чтение**.

Автор: **darkshade** ([@vlx0](https://github.com/vlx0))

**365 дней open source** · **неделя 6 — «Текст»** · **день 39**.

## Что считает

- символы  
- слова  
- время чтения — по умолчанию **замок**; нажми и введи свою скорость (слов/мин)  

Счётчик обновляется пока печатаешь. **Из буфера** — вставить текст.

## Запуск

`start.bat` · `python -m countit` · `run_countit.pyw`
